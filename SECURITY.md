# Security policy

Scout is pre-1.0. Security fixes are provided for the latest release and the default branch.

Please report vulnerabilities using GitHub's private security advisory feature for this repository. Do not open a public issue or include live credentials, private workspace content, or exploit data in logs. Include affected versions, impact, reproduction steps, and a minimal proof of concept when safe.

If private advisories are unavailable, contact the maintainer through their public GitHub profile without sending sensitive details until a secure channel is established. You should receive an acknowledgment within seven days.
