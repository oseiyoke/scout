# Contributing

By contributing, you agree that your contribution is licensed under the repository's MIT License and that you have the right to submit it.

1. Open an issue for substantial behavior or architecture changes.
2. Create a focused branch and avoid committing credentials, personal data, build output, or editor files.
3. Run `npm run check`, `npm run build`, `cargo fmt --check`, and `cargo clippy --all-targets -- -D warnings`.
4. Describe user-visible behavior, security/privacy implications, and manual verification in the pull request.

Security fixes should follow [SECURITY.md](SECURITY.md), not public issues.
